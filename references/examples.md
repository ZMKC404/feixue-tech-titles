# 飞雪科技园标题案例库

以下是虚构练习。每组都给出可用素材、标题取舍和成稿。看案例时借用切口和节奏，具体措辞随新素材调整。

## 1. 软件推荐，默认给 6 条

**用户请求**  
「这篇 Windows 工具推荐，帮我起标题，飞雪味重一点。」

**素材**  
一款 Windows 图片压缩工具。可以把整个文件夹拖进去，离线批量压缩 JPG 和 PNG。能逐张查看压缩前后的文件大小，压缩强度可调，无需注册。批量压缩 JPG、PNG 免费，WebP 转换需付费。

**取舍**  
「整文件夹拖进去」比「图片处理神器」更能说清它省了哪一步。免费角度只落到 JPG、PNG 批量压缩。成稿轮换操作、离线、权益、大小对比、强度和免注册切口。

**成稿**

1. **首推** 整个文件夹拖进去，照片一块儿压！
2. 我去，压一堆图还能离线批量来！
3. JPG、PNG批量压，这功能还免费！
4. 图压小了多少？这工具能逐张看大小！
5. 压图下手多重？这个工具可以自己调！
6. Windows批量压图，免注册直接用！

## 2. 实用网站，偏克制，只给标题

**用户请求**  
「给这个网站写 3 条，公众号用，克制一点，只给标题。」

**素材**  
一个浏览器工具，把粘贴进来的 Markdown 表格转换为 CSV。手机和电脑浏览器都可用，无需注册。

**取舍**  
对象虽然没给名称，Markdown 转 CSV 已经足够具体。分别写省步骤、手机也能做、免注册。用口语问句和短停顿保留节奏。

**成稿**

1. Markdown表格转CSV，粘进去就行
2. 手机上也能转CSV？浏览器就能搞定
3. 免注册，Markdown表格直接转CSV

## 3. 工具合集，数量与人群

**用户请求**  
「三款工具的合集，给我 3 条，读者是日常办公的 Windows 用户。」

**素材**  
三款 Windows 工具，分别支持截图取字、批量改文件名、清理重复文件。三款工具所述功能均可免费使用。

**取舍**  
「三款」能交代合集体量。标题可从办公人群或具体操作切入。免费范围限于稿子介绍的功能。

**成稿**

1. **首推** 截图取字、批量改名，这3个办公工具真省事！
2. 打工人收好！这3个工具，取字改名清重复都免费
3. 文件多到头疼？这3个工具帮你取字、改名、找重复

## 4. 版本更新，留住平台与功能范围

**用户请求**  
「给这次更新起 3 条标题，可以有点惊喜。」

**素材**  
虚构产品「格子笔记」发布 Windows 2.4 正式版。这一版新增整本笔记导出为 Markdown。手机端的导出功能仍处于内测。

**取舍**  
版本号、Windows 和「整本导出」各有作用。保留 Windows 范围，优先强调一次导出整本的变化。手机内测如需入题，按内测写。

**成稿**

1. **首推** 格子笔记更新！Windows上能整本导出Markdown了
2. 笔记还能整本导？格子笔记Windows 2.4来了！
3. Windows版格子笔记，一口气导出整本笔记！

## 5. 改写旧标题，保留限制，只给一条

**用户请求**  
「只改这一条，改成飞雪口吻，28 个字符以内。」

**素材**  
原标题为「这款录音工具的专业版开放 7 天免费试用」。免费试用从激活当天算起。

**取舍**  
「7 天」「试用」一起保留。亮点是录音工具专业版的试用机会，反问和惊叹都可以省掉。

**成稿**

这录音工具的专业版，能免费试7天！

## 6. 科技动态，区分网传与官方结论

**用户请求**  
「这条科技动态给我 3 个标题，写得像公众号。」

**素材**  
部分用户发帖称虚构产品「云盒笔记」的同步变慢。官方回复称正在排查。用户猜测服务即将停止，官方尚未发布停服通知。

**取舍**  
已知的新闻点是用户反馈变慢，以及官方正在排查。把传言改成确定事件会扩大素材里的结论。标题可用问句承接反馈，下一拍补上排查状态。

**成稿**

1. **首推** 云盒笔记同步变慢？官方正在查
2. 有人说云盒笔记同步变慢了，官方回应正在排查
3. 云盒笔记被反馈同步变慢，官方已着手排查

## 7. 筛选已有标题，按事实选首推

**用户请求**  
「这 3 条帮我选一条，说一句理由。」

**素材**  
作者用自家宽带测试了一个文件，记录到峰值 80 MB/s。

**候选**

1. 「不限速！这工具全程跑满80 MB/s！」
2. 「我去，实测峰值80 MB/s！」
3. 「全网最快的下载神器，终于被我找到了！」

**取舍**  
第 2 条把数字限定在实测峰值。第 1 条把峰值扩大成全程表现和不限速。第 3 条的排名和个人经历超出素材。

**成稿**

**首推** 我去，实测峰值80 MB/s！  
它把可核实的亮点直接写出来，并保留了「实测峰值」的条件。

## 8. 素材太少，集中问一个问题

**用户请求**  
「给『小羽工具箱』写 6 个飞雪风格的标题。」

**素材**  
现有素材为产品名「小羽工具箱」。

**取舍**  
产品名本身给不出具体点击理由。问一个能拿到场景和卖点的问题。

**成稿**

「小羽工具箱」主要帮用户省掉哪一步？给我一个最有亮点的功能就行。
